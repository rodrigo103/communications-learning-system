## Ejercicio 1: Modulación Exponencial (Armstrong FM) [2,5 puntos]

### Datos

| Parametro | NBFM | Salida antena |
|-----------|------|---------------|
| $\Delta f$ | 150 Hz | 75 kHz |
| $f_c$ | 200 kHz | 98.3 MHz |
| $f_m$ (modulante) | 30 Hz – 15 kHz | 30 Hz – 15 kHz |

### a) Diagrama en bloques [0,5 puntos]

```
m(t) → [Integrador] → [Modulador de PM] → [Multiplicador × n] → [Mezclador] → [Filtro PB] → [Amp] → Antena
                          ↑                     │                    ↑
                     Oscilador 200 kHz           │              Oscilador f_OL
                                                 │
                                         fc' = 200k × n    fc_out = |fc' ± f_OL| = 98.3 MHz
```

La etapa NBFM se implementa con un modulador de PM precedido por un integrador (PM con $m(t)$ integrada = FM). La desviación de fase se mantiene pequeña ($\beta' \ll 1$) para operar en banda angosta. Luego se multiplica en frecuencia para alcanzar la desviación deseada, se mezcla con un oscilador local para ajustar la portadora, se filtra y se amplifica.

### b) Factor de multiplicación [0,5 puntos]

$$\boxed{n = \frac{\Delta f_{out}}{\Delta f_{NBFM}} = \frac{75\ \text{kHz}}{150\ \text{Hz}} = 500}$$

### c) Oscilador local [0,5 puntos]

Frecuencia a la salida del multiplicador:

$$f_c' = n \cdot f_{c,NBFM} = 500 \times 200\ \text{kHz} = 100\ \text{MHz}$$

A la salida del mezclador: $|f_c' \pm f_{OL}| = 98.3\ \text{MHz}$

$$\boxed{f_{OL} = 100\ \text{MHz} - 98.3\ \text{MHz} = 1.7\ \text{MHz}}$$

(Se elige la diferencia para usar el oscilador de frecuencia más baja.)

### d) Ancho de banda [1 punto]

**En antena (salida, WBFM):**

$$\beta = \frac{\Delta f}{f_{m,max}} = \frac{75\ \text{kHz}}{15\ \text{kHz}} = 5$$

Regla de Carson:

$$\boxed{B_T = 2(\Delta f + f_{m,max}) = 2(75\text{k} + 15\text{k}) = 180\ \text{kHz}}$$

**A la salida del NBFM:**

$$\beta' = \frac{\Delta f_{NBFM}}{f_{m,max}} = \frac{150\ \text{Hz}}{15\ \text{kHz}} = 0.01 \ll 0.2 \quad\Rightarrow\quad \text{NBFM confirmado}$$

$$\boxed{B_{NBFM} \approx 2 \cdot f_{m,max} = 30\ \text{kHz}}$$

## Ejercicio 2: Modulación por Codificación de Pulsos (PCM) [2,5 puntos]

### a) Diagrama en bloques del generador PCM [0,5 puntos]

```
m(t) → [Filtro PB antialiasing] → [Muestreador] → [Cuantificador] → [Codificador] → PCM out
       (limita a f_m)               (f_s ≥ 2f_m)     (M niveles)      (n bits)
```

### b) Función de cada elemento [0,5 puntos]

- **Filtro PB antialiasing:** limita el ancho de banda de $m(t)$ a $f_m$ para que se cumpla el teorema de muestreo ($f_s \geq 2f_m$). Evita que frecuencias por encima de $f_s/2$ produzcan aliasing.
- **Muestreador:** toma valores instantáneos de $m(t)$ a intervalos $T_s = 1/f_s$, generando una señal PAM.
- **Cuantificador:** asigna a cada muestra el nivel discreto más cercano de un conjunto de $M$ niveles, introduciendo error de cuantificación.
- **Codificador:** convierte cada nivel cuantificado a un código binario de $n = \log_2 M$ bits. Cada muestra se representa como una palabra de $n$ bits.

### c) SNR con $P_e = 10^{-8}$ [0,75 puntos]

La expresión dada es:

$$\frac{S}{N}_{out} = \frac{M^2}{1 + 4P_e(M^2 - 1)}$$

**Paso 1 — Hallar $M^2$ a partir de los datos con $P_e = 10^{-6}$:**

$$\frac{S}{N}_{out}\Big|_{P_e=10^{-6}} = 47.2\ \text{dB} = 10^{4.72} \approx 52481$$

$$\frac{M^2}{1 + 4\cdot 10^{-6}(M^2 - 1)} = 52481$$

Resolviendo iterativamente:

- $M^2 \approx 52481$ → $4\cdot 10^{-6} \cdot 52480 = 0.210$ → $M^2 = 52481 \times 1.210 = 63500$
- $M^2 = 63500$ → $4\cdot 10^{-6} \cdot 63499 = 0.254$ → $M^2 = 52481 \times 1.254 = 65810$
- $M^2 = 65810$ → $4\cdot 10^{-6} \cdot 65809 = 0.263$ → $M^2 = 52481 \times 1.263 = 66283$
- Converge a $M^2 \approx 66420$

**Paso 2 — Calcular SNR para $P_e = 10^{-8}$:**

$$\frac{S}{N}_{out}\Big|_{P_e=10^{-8}} = \frac{66420}{1 + 4\cdot 10^{-8}(66420 - 1)} = \frac{66420}{1 + 0.002657} = \frac{66420}{1.002657} \approx 66244$$

$$\boxed{\frac{S}{N}_{out} = 10\log_{10}(66244) \approx 48.21\ \text{dB}}$$

### d) SNR antes del canal [0,75 puntos]

Antes de ingresar al canal no hay errores de transmisión ($P_e = 0$). Solo actúa el ruido de cuantificación:

$$\frac{S}{N}_{antecanal} = M^2 \approx 66420$$

$$\boxed{\frac{S}{N}_{antecanal} = 10\log_{10}(66420) \approx 48.22\ \text{dB}}$$

Notar que la diferencia con 47.2 dB ($P_e = 10^{-6}$) se debe al término del canal en el denominador, y con 48.21 dB ($P_e = 10^{-8}$) es mínima: el ruido de cuantificación domina completamente sobre los errores de canal para $P_e$ tan bajos.

## Ejercicio 3: Modulación Digital [2,5 puntos]

### Datos

| Parámetro | Valor |
|-----------|-------|
| $R_b$ | 400 kbps |
| Formato | Unipolar NRZ (pulsos rectangulares) |
| $N_0$ | $10^{-17}$ W/Hz |
| $\text{SNR}_{in}$ | 14 dB |
| $P_e$ | $Q\left(\sqrt{\dfrac{E_d}{2N_0}}\right)$ |

### a) Ancho de banda mínimo [0,5 puntos]

Para señalización binaria en banda base, el ancho de banda mínimo de Nyquist es:

$$\boxed{BW_{min} = \frac{R_s}{2} = \frac{R_b}{2} = 200\ \text{kHz}}$$

(Con pulsos rectangulares el primer nulo espectral está en $R_b = 400$ kHz, pero el mínimo teórico para ISI cero con pulsos de Nyquist es $R_s/2$.)

### b) Probabilidad de error [1 punto]

**Relación entre $E_d$ y la señal recibida:**

Para unipolar NRZ con amplitudes $V$ (bit 1) y $0$ (bit 0), con bits equiprobables:

- Potencia promedio recibida: $S = \frac{V^2}{2}$
- Energía diferencia: $E_d = V^2 T_b$
- $E_d = 2S \cdot T_b = \frac{2S}{R_b}$

**Cálculo de $S$:**

$$\text{SNR}_{in} = 14\ \text{dB} = 10^{1.4} = 25.12$$

$$N = N_0 \cdot BW_{min} = 10^{-17} \times 200000 = 2 \times 10^{-12}\ \text{W}$$

$$S = \text{SNR}_{in} \cdot N = 25.12 \times 2 \times 10^{-12} = 5.024 \times 10^{-11}\ \text{W}$$

**Cálculo de $E_d/(2N_0)$:**

$$E_d = \frac{2S}{R_b} = \frac{2 \times 5.024 \times 10^{-11}}{4 \times 10^5} = 2.512 \times 10^{-16}\ \text{J}$$

$$\frac{E_d}{2N_0} = \frac{2.512 \times 10^{-16}}{2 \times 10^{-17}} = 12.56$$

**Probabilidad de error:**

$$\sqrt{\frac{E_d}{2N_0}} = \sqrt{12.56} \approx 3.544$$

$$P_e = Q(3.544)$$

Del ábaco de la función $Q(k)$ provisto en el examen: $Q(3.54) \approx 2 \times 10^{-4}$.

$$\boxed{P_e \approx 2 \times 10^{-4}}$$

### c) Señal a la salida del multiplicador [0,5 puntos]

La señal unipolar NRZ (banda base) se multiplica por $\cos(2\pi f_c t)$ de amplitud unitaria:

$$s(t) = 
\begin{cases}
V \cdot \cos(2\pi f_c t) & \text{bit } 1 \\
0 & \text{bit } 0
\end{cases}$$

Esto es **ASK (OOK — On-Off Keying)**: modulación digital de amplitud con portadora senoidal. La señal banda base unipolar se traslada a frecuencia $f_c$ conservando la misma tasa de bits.

### d) Ancho de banda mínimo de la señal ASK [0,5 puntos]

Para una señal paso-banda, el ancho de banda mínimo de Nyquist es el doble que en banda base:

$$\boxed{BW_{min}^{ASK} = 2 \cdot BW_{min}^{BB} = R_s = 400\ \text{kHz}}$$

(Con pulsos rectangulares, el ancho de banda nulo-a-nulo es $2R_b = 800$ kHz.)

### e) Potencia de transmisión [0,5 puntos]

Atenuación del canal: $L = 30$ dB. La potencia recibida es $S = 5.024 \times 10^{-11}$ W.

$$P_{rx}\ \text{[dBm]} = 10\log_{10}\left(\frac{5.024 \times 10^{-11}}{10^{-3}}\right) = 10\log_{10}(5.024 \times 10^{-8})$$

$$= 10 \times (\log_{10}5.024 - 8) = 10 \times (0.701 - 8) = -72.99\ \text{dBm}$$

$$P_{tx}\ \text{[dBm]} = P_{rx}\ \text{[dBm]} + L = -72.99 + 30$$

$$\boxed{P_{tx} \approx -43\ \text{dBm}}$$

## Ejercicio 4: Teoría de la Información [2,5 puntos]

### Datos

| Parámetro | Valor |
|-----------|-------|
| $B$ (ancho de banda) | 1 MHz |
| $R$ (tasa de información) | 20 Mbps |

### a) Mínima SNR teórica [0,5 puntos]

Del teorema de Shannon-Hartley: $C = B\log_2(1 + S/N)$. Para que la transmisión sea posible: $R \leq C$.

$$R \leq B \log_2(1 + \text{SNR})$$

$$20 \times 10^6 \leq 10^6 \cdot \log_2(1 + \text{SNR})$$

$$\log_2(1 + \text{SNR}) \geq 20$$

$$1 + \text{SNR} \geq 2^{20} = 1\,048\,576$$

$$\boxed{\text{SNR}_{min} = 10\log_{10}(1\,048\,575) \approx 60.2\ \text{dB}}$$

Este valor tan elevado se debe a que $R/B = 20$ bits/s/Hz es una eficiencia espectral muy alta — se necesita una SNR enorme para lograrla.

### b) Máxima tasa de símbolos [0,5 puntos]

Por el criterio de Nyquist, la máxima tasa de símbolos en un canal de ancho de banda $B$ es:

$$\boxed{R_{s,max} = 2B = 2\ \text{Msímbolos/s}}$$

### c) Demostración del SNR de salida [1,5 puntos]

**Enunciado a demostrar:**

$$(S/N)_{salida} = \left[1 + (S/N)_{entrada}\right]^{B_T/B} - 1$$

**Demostración:**

La expresión de Shannon-Hartley para el canal original (banda base, ancho de banda $B$) es:

$$C = B \log_2\left[1 + (S/N)_{entrada}\right]$$

Esta capacidad $C$ representa la máxima tasa de información que puede transmitirse sin errores a través de un canal de ancho de banda $B$ con relación señal a ruido $(S/N)_{entrada}$.

Si la misma información se transmite mediante una señal pasabanda de ancho de banda $B_T$, el demodulador —luego del procesamiento— entrega una señal en banda base con ancho de banda $B$ y relación señal a ruido $(S/N)_{salida}$. La capacidad de este sistema debe ser la misma:

$$C = B \log_2\left[1 + (S/N)_{salida}\right]$$

Igualando ambas expresiones (la información transmitida es la misma):

$$B \log_2\left[1 + (S/N)_{salida}\right] = B_T \log_2\left[1 + (S/N)_{entrada}\right]$$

Despejando:

$$\log_2\left[1 + (S/N)_{salida}\right] = \frac{B_T}{B} \log_2\left[1 + (S/N)_{entrada}\right]$$

$$1 + (S/N)_{salida} = \left[1 + (S/N)_{entrada}\right]^{B_T/B}$$

$$\boxed{(S/N)_{salida} = \left[1 + (S/N)_{entrada}\right]^{B_T/B} - 1}$$

∎

**Interpretación física:** cuando $B_T > B$ (señal pasabanda más ancha que la banda base original), el exponente $B_T/B > 1$, y la SNR de salida crece exponencialmente respecto a la de entrada. Esto es el **trade-off fundamental de Shannon**: se puede intercambiar ancho de banda por relación señal a ruido. A mayor ancho de banda $B_T$, menor SNR de entrada se necesita para lograr la misma calidad a la salida. Es la base teórica del espectro expandido y de las modulaciones con ganancia de procesamiento (FM, PCM, CDMA).
