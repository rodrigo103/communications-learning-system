## Ejercicio 1: Modulación Exponencial (Armstrong FM) [2,5 puntos]

### Datos

| Parametro | NBFM | Salida antena |
|-----------|------|---------------|
| $\Delta f$ | 150 Hz | 75 kHz |
| $f_c$ | 200 kHz | 98.3 MHz |
| $f_m$ (modulante) | 30 Hz – 15 kHz | 30 Hz – 15 kHz |

### a) Diagrama en bloques [0,5 puntos]

```
m(t) → [Integrador] → [Modulador de PM] → [Multiplicador × n] → [Mezclador] → [Filtro PB] → [Amp] → Antena
                          ↑                     │                    ↑
                     Oscilador 200 kHz           │              Oscilador f_OL
                                                 │
                                         fc' = 200k × n    fc_out = |fc' ± f_OL| = 98.3 MHz
```

La etapa NBFM se implementa con un modulador de PM precedido por un integrador (PM con $m(t)$ integrada = FM). La desviación de fase se mantiene pequeña ($\beta' \ll 1$) para operar en banda angosta. Luego se multiplica en frecuencia para alcanzar la desviación deseada, se mezcla con un oscilador local para ajustar la portadora, se filtra y se amplifica.

### b) Factor de multiplicación [0,5 puntos]

$$\boxed{n = \frac{\Delta f_{out}}{\Delta f_{NBFM}} = \frac{75\ \text{kHz}}{150\ \text{Hz}} = 500}$$

> **Unidades**: Hz/Hz → $n$ es **adimensional**, un factor de multiplicación puro. Correcto, porque el multiplicador escala la fase entera. Y la multiplicación total la fija **la desviación** (no la portadora) porque el mezclador posterior **no toca $\Delta f$** — ver [[../../wiki/modulacion-analogica/exponencial-formulario-examen#Multiplicadores y mezcladores — el patrón más testeado|multiplicadores vs mezcladores]].

### c) Oscilador local [0,5 puntos]

Frecuencia a la salida del multiplicador:

$$f_c' = n \cdot f_{c,NBFM} = 500 \times 200\ \text{kHz} = 100\ \text{MHz}$$

A la salida del mezclador: $|f_c' \pm f_{OL}| = 98.3\ \text{MHz}$

$$\boxed{f_{OL} = 100\ \text{MHz} - 98.3\ \text{MHz} = 1.7\ \text{MHz}}$$

(Se elige la diferencia para usar el oscilador de frecuencia más baja.)

### d) Ancho de banda [1 punto]

**En antena (salida, WBFM):**

$$\beta = \frac{\Delta f}{f_{m,max}} = \frac{75\ \text{kHz}}{15\ \text{kHz}} = 5$$

Regla de Carson:

$$\boxed{B_T = 2(\Delta f + f_{m,max}) = 2(75\text{k} + 15\text{k}) = 180\ \text{kHz}}$$

**A la salida del NBFM:**

$$\beta' = \frac{\Delta f_{NBFM}}{f_{m,max}} = \frac{150\ \text{Hz}}{15\ \text{kHz}} = 0.01 \ll 0.2 \quad\Rightarrow\quad \text{NBFM confirmado}$$

$$\boxed{B_{NBFM} \approx 2 \cdot f_{m,max} = 30\ \text{kHz}}$$

## Ejercicio 2: Modulación por Codificación de Pulsos (PCM) [2,5 puntos]

### a) Diagrama en bloques del generador PCM [0,5 puntos]

```
m(t) → [Filtro PB antialiasing] → [Muestreador] → [Cuantificador] → [Codificador] → PCM out
       (limita a f_m)               (f_s ≥ 2f_m)     (M niveles)      (n bits)
```

### b) Función de cada elemento [0,5 puntos]

- **Filtro PB antialiasing:** limita el ancho de banda de $m(t)$ a $f_m$ para que se cumpla el teorema de muestreo ($f_s \geq 2f_m$). Evita que frecuencias por encima de $f_s/2$ produzcan aliasing.
- **Muestreador:** toma valores instantáneos de $m(t)$ a intervalos $T_s = 1/f_s$, generando una señal PAM.
- **Cuantificador:** asigna a cada muestra el nivel discreto más cercano de un conjunto de $M$ niveles, introduciendo error de cuantificación.
- **Codificador:** convierte cada nivel cuantificado a un código binario de $n = \log_2 M$ bits. Cada muestra se representa como una palabra de $n$ bits.

### c) SNR con $P_e = 10^{-8}$ [0,75 puntos]

La expresión dada es:

$$\frac{S}{N}_{out} = \frac{M^2}{1 + 4P_e(M^2 - 1)}$$

**Paso 1 — Hallar $M^2$ a partir de los datos con $P_e = 10^{-6}$:**

$$\frac{S}{N}_{out}\Big|_{P_e=10^{-6}} = 47.2\ \text{dB} = 10^{4.72} \approx 52481$$

$$\frac{M^2}{1 + 4\cdot 10^{-6}(M^2 - 1)} = 52481$$

**No hace falta iterar** — se despeja directo, porque $M^2$ aparece linealmente en ambos lados:

$$M^2 = 52481\big[1 + 4\times10^{-6}(M^2-1)\big] \ \Rightarrow\ M^2\big(1 - 0{,}20992\big) = 52480{,}8$$

$$M^2 = \frac{52480{,}8}{0{,}79008} = 66\,400$$

> ⚠️ **Chequeo obligatorio: $M$ tiene que ser potencia de 2.** De $M^2 = 66\,400$ sale $M = 257{,}7$, que **no es un número válido de niveles**. El valor físico más cercano es
> $$\boxed{M = 256 = 2^8 \quad\Rightarrow\quad n = 8\ \text{bits/muestra}}$$
> **Verificación**: con $M=256$ ($M^2=65\,536$), $\frac{65536}{1+4\times10^{-6}(65535)} = \frac{65536}{1{,}2621} = 51\,925 \to 47{,}15$ dB — que es el enunciado (47,2 dB) redondeado. **Confirma que $M=256$ es el dato real**; los 66.400 son el artefacto de tomar "47,2 dB" al pie de la letra. [analysis]
>
> Este chequeo vale doble: además de dar el valor correcto, **detecta errores de cálculo**. Si $M$ no sale cerca de una potencia de 2, hay algo mal.

**Paso 2 — Calcular SNR para $P_e = 10^{-8}$** (usando $M^2 = 65\,536$):

$$\frac{S}{N}_{out}\Big|_{P_e=10^{-8}} = \frac{65\,536}{1 + 4\times10^{-8}(65\,535)} = \frac{65\,536}{1{,}00262} = 65\,365$$

$$\boxed{\frac{S}{N}_{out} = 10\log_{10}(65\,365) \approx 48{,}15\ \text{dB}}$$

### d) SNR antes del canal [0,75 puntos]

Antes de ingresar al canal no hay errores de transmisión ($P_e = 0$), así que el denominador vale 1 y **queda solo el numerador** — el ruido de cuantificación:

$$\frac{S}{N}_{antecanal} = M^2 = 65\,536$$

$$\boxed{\frac{S}{N}_{antecanal} = 10\log_{10}(65\,536) \approx 48{,}16\ \text{dB}}$$

**Unidades**: $M$ es un **conteo de niveles** (adimensional), así que $M^2$ y toda la SNR son **números puros** — que es lo que permite expresarla en dB.

> **Por qué el numerador es $M^2$ y no $3M^2/F_C^2$**: el enunciado está asumiendo **señal uniformemente distribuida**, donde $F_C=\sqrt3$ y entonces $3M^2/3 = M^2$. Ver [[../../wiki/modulacion-pulsos/pcm-formulario-examen#SNR de PCM **con errores de canal**|PCM — SNR con errores de canal]].

**Lectura de los tres valores** (el punto conceptual del ejercicio):

| $P_e$ | $(S/N)_{out}$ | Qué domina |
|---|---|---|
| $10^{-6}$ | 47,15 dB | El canal degrada ~1 dB |
| $10^{-8}$ | 48,15 dB | Canal casi irrelevante |
| $0$ (antes del canal) | 48,16 dB | **Solo cuantificación** |

El denominador es siempre $\geq1$, así que **el canal solo puede empeorar**. Con $P_e = 10^{-8}$ la diferencia contra el caso ideal es de **0,01 dB**: el sistema está **limitado por cuantificación**, no por el canal. Bajar más el $P_e$ no mejora nada — para ganar SNR habría que agregar bits ($+6$ dB por bit).

## Ejercicio 3: Modulación Digital [2,5 puntos]

### Datos

| Parámetro | Valor |
|-----------|-------|
| $R_b$ | 400 kbps |
| Formato | Unipolar NRZ (pulsos rectangulares) |
| $N_0$ | $10^{-17}$ W/Hz |
| $\text{SNR}_{in}$ | 14 dB |
| $P_e$ | $Q\left(\sqrt{\dfrac{E_d}{2N_0}}\right)$ |

### a) Ancho de banda mínimo [0,5 puntos]

Para señalización binaria en banda base, el ancho de banda mínimo de Nyquist es:

$$\boxed{BW_{min} = \frac{R_s}{2} = \frac{R_b}{2} = 200\ \text{kHz}}$$

> **Por qué $R_s = R_b$ acá**: la señalización es **binaria** ($M=2$), así que $\ell=\log_2 2 = 1$ **bit/símbolo** y entonces $R_s = R_b/\ell = R_b$ — **numéricamente iguales, pero unidades distintas**: $R_b = 400$ kbps (bits/s) y $R_s = 400$ kbaudios (símbolos/s). Recién con $M>2$ se separan.
>
> **Y el paso $R_s \to BW$**: $\frac{R_s}{2}$ divide símbolos/s por 2 [símbolos/ciclo] → ciclos/s = Hz ✓

(Con pulsos rectangulares el primer nulo espectral está en $R_b = 400$ kHz, pero el mínimo teórico para ISI cero con pulsos de Nyquist es $R_s/2$ — ver [[../../wiki/herramientas-matematicas/pulsos-y-cota-de-nyquist|Pulsos y la cota de Nyquist]].)

### b) Probabilidad de error [1 punto]

**Relación entre $E_d$ y la señal recibida:**

Para unipolar NRZ con amplitudes $V$ (bit 1) y $0$ (bit 0), con bits equiprobables:

- Potencia promedio recibida: $S = \frac{V^2}{2}$
- Energía diferencia: $E_d = V^2 T_b$
- $E_d = 2S \cdot T_b = \frac{2S}{R_b}$

**Cálculo de $S$:**

$$\text{SNR}_{in} = 14\ \text{dB} = 10^{1.4} = 25.12$$

$$N = N_0 \cdot BW_{min} = 10^{-17} \times 200000 = 2 \times 10^{-12}\ \text{W}$$

$$S = \text{SNR}_{in} \cdot N = 25.12 \times 2 \times 10^{-12} = 5.024 \times 10^{-11}\ \text{W}$$

**Cálculo de $E_d/(2N_0)$:**

$$E_d = \frac{2S}{R_b} = \frac{2 \times 5.024 \times 10^{-11}}{4 \times 10^5} = 2.512 \times 10^{-16}\ \text{J}$$

$$\frac{E_d}{2N_0} = \frac{2.512 \times 10^{-16}}{2 \times 10^{-17}} = 12.56$$

**Probabilidad de error:**

$$\sqrt{\frac{E_d}{2N_0}} = \sqrt{12.56} \approx 3.544$$

$$P_e = Q(3.544)$$

Del ábaco de la función $Q(k)$ provisto en el examen: $Q(3.54) \approx 2 \times 10^{-4}$.

$$\boxed{P_e \approx 2 \times 10^{-4}}$$

### c) Señal a la salida del multiplicador [0,5 puntos]

La señal unipolar NRZ (banda base) se multiplica por $\cos(2\pi f_c t)$ de amplitud unitaria:

$$s(t) = 
\begin{cases}
V \cdot \cos(2\pi f_c t) & \text{bit } 1 \\
0 & \text{bit } 0
\end{cases}$$

Esto es **ASK (OOK — On-Off Keying)**: modulación digital de amplitud con portadora senoidal. La señal banda base unipolar se traslada a frecuencia $f_c$ conservando la misma tasa de bits.

**¿Cuál es el beneficio de ASK?** Cuatro, en orden de importancia:

**1. Permite la transmisión por radio** *(el motivo central, y el que justifica el multiplicador de este ejercicio)*. La señal en banda base **no se puede radiar**: tiene contenido hasta continua, y una antena eficiente requiere dimensiones del orden de $\lambda/4$ — para 400 kbps en banda base harían falta antenas de cientos de metros. Trasladar a $f_c$ permite antenas de tamaño práctico, y además **asignar la señal a una banda del espectro** para que convivan múltiples usuarios (FDM).

**2. Simplicidad del modulador**: es literalmente un multiplicador, o incluso una **llave que enciende y apaga la portadora** ("on-off"). No hay circuito más simple para modular digitalmente.

**3. Admite detección no coherente**: como la información está en la **amplitud**, alcanza un **detector de envolvente** (diodo + RC) — **no hace falta recuperar la portadora** (ni PLL ni lazo de Costas). Receptores muy baratos. Es la misma ventaja que tiene AM completa sobre DSB-SC.

**4. Bajo consumo promedio**: durante los "0" **no se transmite nada**, así que la potencia media es la mitad de la de pico. Por eso OOK se usa en controles remotos, RFID, sensores a batería.

> **El precio** (conviene mencionarlo si piden comparar): ASK/OOK es **3 dB peor que BPSK** ($k=E_d/E_b=2$ contra $4$ — ver [[../../wiki/modulacion-digital/digital-formulario-examen#La forma general con filtro acoplado: energía diferencia $E_d$|formulario de Digital]]), y al llevar la información en la amplitud es **sensible al desvanecimiento y al ruido multiplicativo**, además de necesitar una **referencia de amplitud** (umbral) en el receptor. Y el traslado a pasabanda **duplica el ancho de banda** — lo que se calcula en el ítem d).

### d) Ancho de banda mínimo de la señal ASK [0,5 puntos]

Para una señal paso-banda, el ancho de banda mínimo de Nyquist es el doble que en banda base:

$$\boxed{BW_{min}^{ASK} = 2 \cdot BW_{min}^{BB} = R_s = 400\ \text{kHz}}$$

(Con pulsos rectangulares, el ancho de banda nulo-a-nulo es $2R_b = 800$ kHz.)

### e) Potencia de transmisión [0,5 puntos]

Atenuación del canal: $L = 30$ dB. La potencia recibida es $S = 5.024 \times 10^{-11}$ W.

$$P_{rx}\ \text{[dBm]} = 10\log_{10}\left(\frac{5.024 \times 10^{-11}}{10^{-3}}\right) = 10\log_{10}(5.024 \times 10^{-8})$$

$$= 10 \times (\log_{10}5.024 - 8) = 10 \times (0.701 - 8) = -72.99\ \text{dBm}$$

$$P_{tx}\ \text{[dBm]} = P_{rx}\ \text{[dBm]} + L = -72.99 + 30$$

$$\boxed{P_{tx} \approx -43\ \text{dBm}}$$

## Ejercicio 4: Teoría de la Información [2,5 puntos]

### Datos

| Parámetro | Valor |
|-----------|-------|
| $B$ (ancho de banda) | 1 MHz |
| $R$ (tasa de información) | 20 Mbps |

### a) Mínima SNR teórica [0,5 puntos]

Del teorema de Shannon-Hartley: $C = B\log_2(1 + S/N)$. Para que la transmisión sea posible: $R \leq C$.

$$R \leq B \log_2(1 + \text{SNR})$$

$$20 \times 10^6\ \tfrac{\text{bits}}{\text{s}} \leq 10^6\ \tfrac{\text{ciclos}}{\text{s}} \cdot \log_2(1 + \text{SNR})$$

$$\log_2(1 + \text{SNR}) \geq 20\ \tfrac{\text{bits}}{\text{ciclo}}$$

$$1 + \text{SNR} \geq 2^{20} = 1\,048\,576$$

$$\boxed{\text{SNR}_{min} = 10\log_{10}(1\,048\,575) \approx 60.2\ \text{dB}}$$

> **Contabilidad de unidades de Shannon-Hartley**: $C$ está en bits/s y $B$ en Hz = ciclos/s, así que el factor $\log_2(1+S/N)$ **tiene que llevar bits/ciclo** para que la ecuación cierre:
> $$C\left[\tfrac{\text{bits}}{\text{s}}\right] = B\left[\tfrac{\text{ciclos}}{\text{s}}\right] \times \underbrace{\log_2(1+S/N)}_{\left[\tfrac{\text{bits}}{\text{ciclo}}\right]}$$
> Los ciclos se cancelan. **Y ese factor es exactamente la eficiencia espectral** $\eta = C/B$ [bits/s/Hz]: cuántos bits se pueden meter en cada ciclo de ancho de banda con esa SNR. El $\text{SNR}$ es adimensional (potencia sobre potencia), que es lo que permite meterlo en un logaritmo.

Este valor tan elevado se debe a que $\eta = R/B = 20$ **bits/ciclo** es una eficiencia espectral muy alta — con 1 MHz hay que exprimir 20 bits por ciclo, y eso exige una SNR enorme. Para referencia, 64-QAM da 6 bits/símbolo; llegar a 20 bits/ciclo requeriría una constelación de $2^{20}$ puntos.

### b) Máxima tasa de símbolos [0,5 puntos]

Por el criterio de Nyquist, la máxima tasa de símbolos en un canal de ancho de banda $B$ es:

$$R_{s,max} = 2B = 2\times10^6\ \text{símbolos/s} \ \Rightarrow\ \boxed{R_{s,max} = 2\ \text{Mbaudios}}$$

> **El "2" tiene unidades**: es $2\ \left[\tfrac{\text{símbolos}}{\text{ciclo}}\right]$, así que
> $$R_s\left[\tfrac{\text{símbolos}}{\text{s}}\right] = 2\left[\tfrac{\text{símbolos}}{\text{ciclo}}\right] \times B\left[\tfrac{\text{ciclos}}{\text{s}}\right]$$
> **Contenido físico (el argumento correcto)**: un canal real de ancho de banda $B$ tiene **exactamente $2B$ grados de libertad por segundo** — se pueden elegir libremente $2B$ números independientes por segundo para meter en él. Por eso $R_s\leq2B$: cada símbolo consume un grado de libertad. Ver [[../../wiki/herramientas-matematicas/pulsos-y-cota-de-nyquist|Pulsos y la cota de Nyquist]] para la demostración vía espectro plegado.
>
> ⚠️ **No confundir con el teorema de muestreo** ($f_s\geq2B$): son **teoremas duales, no el mismo**. Comparten el hecho de fondo (los $2B$ grados de libertad por segundo) leído en direcciones opuestas — **muestreo** dice cuántos números *hacen falta* para describir la señal [muestras/ciclo]; **señalización** dice cuántos se pueden *elegir libremente* para transmitir [símbolos/ciclo].

> **Chequeo de consistencia entre a) y b)**: con $R_{s,max}=2$ Mbaudios y $R=20$ Mbps hacen falta $\ell = R/R_s = 20/2 = 10$ **bits/símbolo**, o sea $M=2^{10}=1024$ niveles. Y la SNR necesaria para sostener 1024 niveles es justamente la de ~60 dB del ítem a) — **las dos respuestas describen el mismo sistema desde dos ángulos**. [analysis]

### c) Demostración del SNR de salida [1,5 puntos]

**Enunciado a demostrar:**

$$(S/N)_{salida} = \left[1 + (S/N)_{entrada}\right]^{B_T/B} - 1$$

**Demostración:**

Hay **dos puntos del sistema** donde se puede evaluar la capacidad, y en un sistema ideal deben coincidir:

**1. En el canal de transmisión** (pasabanda, ancho $B_T$, con $(S/N)_{entrada}$ medida ahí):

$$C = B_T \log_2\left[1 + (S/N)_{entrada}\right]$$

**2. A la salida del demodulador** (banda base, ancho $B$, con $(S/N)_{salida}$):

$$C = B \log_2\left[1 + (S/N)_{salida}\right]$$

**Un sistema ideal no pierde información**, así que las dos capacidades son iguales:

$$B \log_2\left[1 + (S/N)_{salida}\right] = B_T \log_2\left[1 + (S/N)_{entrada}\right]$$

Despejando:

$$\log_2\left[1 + (S/N)_{salida}\right] = \frac{B_T}{B} \log_2\left[1 + (S/N)_{entrada}\right]$$

$$1 + (S/N)_{salida} = \left[1 + (S/N)_{entrada}\right]^{B_T/B}$$

$$\boxed{(S/N)_{salida} = \left[1 + (S/N)_{entrada}\right]^{B_T/B} - 1}$$

∎

**Interpretación física:** cuando $B_T > B$ (señal pasabanda más ancha que la banda base original), el exponente $B_T/B > 1$, y la SNR de salida crece exponencialmente respecto a la de entrada. Esto es el **trade-off fundamental de Shannon**: se puede intercambiar ancho de banda por relación señal a ruido. A mayor ancho de banda $B_T$, menor SNR de entrada se necesita para lograr la misma calidad a la salida. Es la base teórica del espectro expandido y de las modulaciones con ganancia de procesamiento (FM, PCM, CDMA).
